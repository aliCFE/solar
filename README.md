# منصة تقييم الطاقة الشمسية (Solar AI Assessment Platform)

منصة تربط الزبون بشركات الطاقة الشمسية العراقية: تحسب احتياجه الفعلي بالذكاء الاصطناعي (ألواح، بطارية، انفيرتر، تخطيط توزيع على السطح)، تطابقه تلقائياً مع باقات شركات مسجلة، وتدير الوسيط بينهم (طلبات، عمولة) بدون ربط مباشر بين الزبون والشركة.

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local
npm run dev
```

افتح http://localhost:3510

### مفاتيح API المطلوبة

| المفتاح | لماذا | إجباري؟ |
|---|---|---|
| `KIMI_API_KEY` أو `ANTHROPIC_API_KEY` | كل ميزات الذكاء الاصطناعي (حساب الاحتياج، قراءة الخرائط والكوتيشنز، تخطيط الألواح، البحث عن شركات) — Kimi يُستخدم تلقائياً لو موجود، وإلا Anthropic | نعم لحساب الاحتياج؛ بدونه يشتغل محرك حساب احتياطي بسيط |
| `TAVILY_API_KEY` | زر "ابحث عن شركات جديدة" بلوحة الإدارة | لا (الميزة تعطي خطأ واضح بدونه) |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | دخول لوحة الإدارة `/admin` | نعم — **غيّرها قبل أي نشر حقيقي** |
| `SESSION_SECRET` | توقيع كوكي جلسات الشركات والإدارة | نعم بالإنتاج |
| `NEXT_PUBLIC_ADSENSE_CLIENT_ID` | إعلانات AdSense | لا (فاضي = ما تظهر إعلانات، طبيعي على localhost) |

## البنية

**حساب الاحتياج (AI-driven)**
- `lib/aiSolarCalc.ts` — يرسل بيانات الزبون + إشعاع شمسي حقيقي (NASA POWER) لنموذج AI يحسب حجم النظام كامل بنفسه؛ لو AI غير متاح يتحول تلقائياً لـ`lib/solarCalc.ts` (محرك احتياطي بمعادلة ثابتة)
- `lib/nasaPower.ts` — بيانات إشعاع شمسي شهرية حقيقية لأي إحداثيات (NASA POWER API، مجاني بدون مفتاح)
- `lib/roofPlanAnalysis.ts` — يقرأ صورة خارطة البيت ويستخرج مساحة السطح من الأبعاد المكتوبة عليها
- `lib/panelLayoutAi.ts` — يصمم تخطيط توزيع أولي للألواح على السطح (شبكة، سلاسل كهربائية، ملاحظات تركيب)

**الذكاء الاصطناعي (متعدد المزودين)**
- `lib/aiProvider.ts` — طبقة موحدة تدعم Kimi (Moonshot، متوافق مع OpenAI) و Anthropic؛ يُختار المزود تلقائياً حسب أي مفتاح موجود — لا كود ميزات يستورد SDK مزود معين مباشرة
- `lib/quoteAnalysis.ts` — قراءة كوتيشنز الشركات (صورة/PDF)، تقييمها مقابل الاحتياج، مقارنة عدة عروض
- `lib/companySearch.ts` — بحث ويب (Serper.dev) + استخراج AI لشركات طاقة شمسية حقيقية

**السوق (Marketplace)**
- تسجيل/دخول شركات (`/register`, `/login`, `/dashboard`) — إدارة الباقات، الأسعار، الصور والفيديوهات
- دليل عام للشركات المعتمدة (`/companies`, `/companies/[slug]`)
- مطابقة تلقائية بين احتياج الزبون وباقات الشركات المعتمدة (`lib/packageMatching.ts`)
- نظام طلبات (Leads) بدون كشف بيانات الزبون للشركة مباشرة — المنصة توسط

**لوحة الإدارة (`/admin`)**
- موافقة/رفض الشركات المسجلة
- إدارة طلبات الزباين وملاحظات العمولة
- "الشركات المكتشفة" — قائمة CRM خاصة لمرشحين قبل التسجيل الرسمي، مع بحث ويب تلقائي

**الحماية**
- `lib/rateLimit.ts` — حد أقصى للطلبات لكل IP على كل نقطة تكلف فلوس أو قابلة للإساءة (حساب AI، رفع ملفات، تسجيل دخول...)

## مراحل لاحقة

- نشر حقيقي على دومين واستضافة (حالياً يشتغل محلياً فقط)
- إشعارات فورية للإدارة (إيميل/واتساب) عند طلب جديد
- نظام تقييمات/مراجعات للشركات بعد إتمام الصفقة
- نقل قاعدة البيانات من SQLite المحلي لقاعدة سحابية عند النشر
