What's built — 6 areas

1. Assessment engine Live, no setup needed

Customer enters home size, monthly electricity use, and location. The system pulls real solar-radiation data for that exact location from NASA's public climate API and sizes the system against the worst month of the year, so it holds up in winter too — not just an optimistic summer estimate. Output: panel count, inverter size, battery capacity, and a cost range.

2. AI quote reader Needs an Anthropic API key

Customer uploads a supplier's quote as a photo or PDF. Claude reads it, pulls out the specs and price, and scores it against the customer's own calculated need — flagging if it's oversized, undersized, or overpriced. Multiple quotes can be compared side by side with a ranked recommendation.

3. Supplier marketplace Live

Companies can register, then manage their own catalog — package specs and prices — from a private dashboard. Approved suppliers get a public profile page, browsable in a company directory.

4. Smart matching Live, no setup needed

Every customer assessment is automatically scored against all approved suppliers' current packages — system size, battery fit, price versus estimate, warranty — and ranked, with the closest match to the customer's actual need labelled as "best offer" and the reasoning shown.

5. Admin approval console Live

A separate owner login for reviewing new supplier sign-ups before they go public — approve, reject, or hold for review. Nothing a company publishes is visible to customers until it's approved.

6. Demo dataset Seeded

Three sample suppliers, five packages each, spanning economy (~$2.8k) to premium commercial (~$39k) tiers — enough to demo the full flow end to end today.

Needs a decision — before a public launch

  • Anthropic API key — required only for the quote-reader and quote-comparison features. Sizing and matching work fully without it.
  • Admin password is a placeholder — must be replaced before this goes anywhere public.
  • Not deployed yet — currently runs on a local machine only; needs hosting to be reachable outside the team.
  • No payment or lead-handoff flow yet — a customer can find the best supplier match but there's no built-in way to request a proposal or pay through the platform. Out of scope for this round.
